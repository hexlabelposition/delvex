# Security Policy

## Supported versions

Security updates are provided for the latest stable Delvex release.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues, pull
requests, or discussions.

Use the **Report a vulnerability** option in the repository's **Security** tab
to submit a private report. Include the affected component and version,
reproduction steps, potential impact, and any suggested remediation.

You will receive an acknowledgement after the report has been reviewed.
